How much do modelling choices change estimated vertebral strength? This GigaScience study compares linear and nonlinear finite element models using density-calibrated CT across the thoracolumbar spine.

The accompanying reference dataset and code support reproducible evaluation of image-based computational models. The work connects medical imaging with estimates of the spine's load-bearing capacity.

This work provides CT-based modelling methods for the lab's spinal mechanobiology research.

[Read the paper](https://doi.org/10.1093/gigascience/giaf094) or [browse the benchmark code](https://github.com/Bonelab/spineFE-benchmark).
