# Lab website design

Approved in conversation: build a parallel, UCalgary-coloured lab website without changing or deploying the personal website. Preserve the accepted interactive trabecular animation. Research themes: Cancer–Bone Mechanobiology; Spinal Alignment & Mechanobiology; Bone Adaptation & Remodelling. Explain imaging, computational modelling, machine/deep learning through concrete applications. Feature SlicerBoneImagingToolbox, selected publications and ORMIR contributions. Do not invent team members, funded positions, radio appearances or active collaborations.

Content is Markdown with JSON metadata between `---` delimiters (JSON is a YAML-compatible subset). One file per person, research project, opportunity, software resource, publication or outreach item. Build static HTML using Node's standard library, with current/alumni and draft/open/closed filtering. Separate project pages are crawlable without JavaScript. Open Positions is a main navigation item; tentative project directions are explicitly not advertised vacancies. An institution-level interactive map derives from the ORCID-matched OpenAlex author, uses paper-time affiliations, cached data, keyboard-accessible institution selection, and a correction file. Unknown coordinates are omitted, not invented. No runtime API dependency or analytics. Refresh is manual initially; document how it can later be scheduled.
